# CareerPath Frontend

AI Career Guide for University Students — Turn your CV into an evidence-backed one-week career plan.

## Quick Start

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

3. Build for production:
```bash
npm run build
```
